# Автономная сборка компилятора Рефала-05

Сборка компилятора [Рефал-05](https://github.com/Mazdaywik/Refal-05), которой не нужен сторонний компилятор Рефала-5: достаточно компилятора C89.

Исходные тексты компилятора и Рефал-5-фреймворка подключены подмодулями и не изменяются, здесь лежит только сборка.
В каталоге `src` лежат скрипты раскрутки, в `autotests` запускатели тестов, а сами исходные тексты и тесты находятся в подмодулях.
В каталоге `bootstrap` хранятся C-файлы, порождённые предыдущей сборкой; раскрутка собирает компилятор из них, перегенерирует их из исходных текстов и пересобирает компилятор заново.

## Сборка

```shell
git clone --recursive https://github.com/butvinm/Refal-05-Standalone
cd Refal-05-Standalone

make bin/refal05c      # Unix
make bin/refal05c.exe  # Windows
```

Если репозиторий склонирован без `--recursive`, скрипты раскрутки подтянут подмодули сами.

Раскрутка заканчивается прогоном автотестов из репозитория Рефала-05.

## Готовые сборки

Исполняемые файлы для Unix и Windows публикуются в релизах.
Тег релиза соответствует ревизии компилятора, на которой зафиксирован подмодуль.

Сборка для Linux статическая, зависимостей от версии glibc у неё нет.
Сборка для Windows использует статическую библиотеку времени выполнения, устанавливать Visual C++ Redistributable не требуется.

## Обновление

Обновление обоих подмодулей автоматическое: раз в неделю рабочий процесс поднимает ревизию, прогоняет раскрутку и автотесты, проверяет неподвижную точку и открывает запрос на слияние, который вливается сам, если проверки прошли.
